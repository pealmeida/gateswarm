## 5. Code-level safety

| Check | Result | Notes |
|---|---|---|
| Untrusted prompt execution (shell injection) | ✅ Clean | The router treats prompts as data; no `eval`, no `child_process.exec(prompt)`. CLI providers use `argsTemplate` with explicit placeholders. |
| HTTP path traversal in `/v05/intel/ops-guide` | ✅ Scoped | Uses `path.join(__dirname, '..', 'docs', 'OPS_GUIDE.md')` — no user input. |
| API key redaction in logs | ✅ Verified | Logs use `***` for `apiKey` substrings and never log full keys. |
| `child_process` calls | ✅ Audited | `scripts/quota-sync.py` uses file paths derived from a list of known providers; `cli-health-probe.sh` validates the agent ID against a hardcoded allowlist before dispatching. |
| Path traversal in the new health probe | ✅ Audited | `GATESWARM_ROOT` is treated as opaque prefix; the probe accepts a single argument validated against an enum (`codex-cli`, `claude-cli`, `pi-agent`, `hermes-agent`, `openclaw-agent`). |
| Open redirects / SSRF | ✅ Clean | The router only calls provider base URLs from `agent-registry.json` (a server-controlled config) plus the localhost listener. No user-supplied URLs are fetched. |
| Dependency vulnerabilities | ⚠️ Not audited in this pass | Recommend `npm audit --production` before each release. The `v0.5.6` build is pinned via `package-lock.json` (cli only) and the root uses `tsx` directly without a lockfile (TODO). |

## 7. Summary of changes in v0.5.6 release

### Code
- `src/agent-registry.ts` — health-check commands replaced with portable `"${GATESWARM_ROOT:-.}"/bin/cli-health-probe.sh <agent>` (no hardcoded paths)
- `data/agent-registry.json` — same change applied to runtime state

### Infra
- `bin/cli-health-probe.sh` — new, auto-locates the router root via `$BASH_SOURCE` (no hardcoded paths)
- `scripts/cli-health-probe.sh` — kept as the canonical source; `bin/` is a copy
- `/etc/systemd/system/moa-gateway.service` — `Environment=GATESWARM_ROOT=...` added

### Git hygiene
- `.gitignore` — added 4 ephemeral `data/*.json` files
- `git rm --cached` — untracked `data/consumption-history.json`, `data/provider-quota.json`, `data/quota-sync.json`, `data/model-matrix.json`

### Docs
- `.env.example` — added ZAI_KEY, OLLAMA_CLOUD_*, OLLAMA_*, GATESWARM_ROOT; comment-clarified
- `gateway/.env.example` — annotated as legacy, points to `../.env.example`
- `docs/OPS_GUIDE.md` — new 25KB operations guide (updates, debugging, analysis, versioning)
- `docs/SECURITY_AUDIT.md` — this document

### Versions
- v0.4.4, v0.5.2, v0.5.6 will be the three retained tags (per request)
- Drop: v0.3.5, v0.5.1, v0.5.1-stable, v0.6.2, `stable`
- Drop branch: `backup/v0.5.1-stable-pre-filter`, `v0.5.1-stable`
